# Proposal

## Why

На планшете многострочная шапка выбранной OpenCode-сессии отнимает значительную высоту у переписки. Пользователь выбрал вариант A с компактной шапкой и явно потребовал сохранить вкладки без изменений.

## What Changes

- Заменить большой блок метаданных компактной горизонтальной строкой: название сессии, текущий статус, управление сведениями.
- Убрать подпись `OpenCode session` и постоянный вывод директории; полный путь показывать по нажатию на сведения.
- Отдать освобождённую высоту существующей прокручиваемой переписке.
- По уточнению пользователя выровнять название, статус и кнопку по вертикальному центру строки.
- Сохранить вкладки, подпись агента, панель эмулятора, сообщения и поле ввода в текущем виде.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `opencode-session-attachment`: компактное представление заголовка выбранной сессии и доступ к полным сведениям по запросу.
- `android-backend-driven-ui`: опциональное вертикальное центрирование детей существующего `row`.

## Impact

Изменение затрагивает TEA-компонент `Session`, существующий `row` и его Android-рендерер, проверки и `README.md`. Для запрошенного центрирования добавляется опциональное поле `centerVertically` у `row`, по умолчанию false. Новые базовые компоненты и зависимости не нужны. Визуальный ориентир — вариант A из папки `~/Desktop/RemoteDev — вкладки без изменений`; содержимое демонстрационных сообщений и их оформление не являются требованиями к реализации.
