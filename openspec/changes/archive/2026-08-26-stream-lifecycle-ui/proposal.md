## Why

Сервер получает начальный UI только после синтетического клиентского события `load`, хотя загрузка списка worktree является командой инициализации самого приложения. Это смешивает запуск lifecycle с пользовательскими событиями.

## What Changes

- Запускать root `init` и его команду загрузки списка worktree до начала приёма HTTP-запросов.
- Добавить получение initial UI без event envelope через `GET /`; ответ возвращает готовую текущую модель одним JSON-документом.
- Возвращать поток UI-документов для `POST`-события, обработка которого запускает обычный UI `Cmd`: сначала документ модели после `update`, затем документ после результата команды. Это распространяется на загрузку списка при возврате к worktree list и на ручной `load`.
- Сделать обработку `application/x-ndjson` общей для Android-клиента для event responses, а не специальной веткой только для успешного `run_claude`.
- Сохранить `POST /` и JSON event envelope для пользовательских backend-defined событий. `load` остаётся пользовательским действием обновления, но перестаёт быть обязательным событием запуска клиента.
- **BREAKING** Заменить начальный `POST /` с `{"event":{"type":"load"},"value":null}` на `GET /`, возвращающий один `application/json` UI-документ.

## Capabilities

### New Capabilities
- `ui-command-streaming`: Поток полных UI-документов, отражающий модель до и после выполнения обычной команды, запущенной UI-событием.

### Modified Capabilities
- `android-backend-driven-ui`: Начальная загрузка через `GET` и обработка потоковых event responses меняют контракт Android-клиента.
- `eio-http-server`: Сервер инициализирует UI до приёма запросов, а HTTP endpoint получает initial UI без event envelope и возвращает поток для UI-команд.
- `claude-output-streaming`: NDJSON перестаёт быть форматом, доступным исключительно для успешного `run_claude`.

## Impact

- Затрагиваются `lib/home.ml` и `lib/server.ml`: root lifecycle, выполнение `Cmd` и формирование HTTP response.
- Затрагивается Android-клиент и его протокол чтения `application/x-ndjson`.
- Изменяются HTTP-контракт, README и существующие спецификации; новых зависимостей не требуется.
