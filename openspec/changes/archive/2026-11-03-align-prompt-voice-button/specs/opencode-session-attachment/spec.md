# Spec Delta

## ADDED Requirements

### Requirement: Prompt controls vertical alignment
The OpenCode chat SHALL vertically center the voice-input button relative to the prompt field so that the send and microphone buttons share the same vertical center. Prompt submission and voice-input behavior SHALL remain unchanged.

#### Scenario: Display prompt controls
- **WHEN** an OpenCode chat displays its prompt field and voice-input button
- **THEN** the send and microphone buttons have matching vertical centers
