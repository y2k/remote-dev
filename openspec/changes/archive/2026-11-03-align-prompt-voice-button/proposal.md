# Proposal

## Why

На экране чата OpenCode микрофон расположен выше кнопки отправки: общая строка выравнивает поле и микрофон по верхнему краю, а отправка центрирована внутри поля.

## What Changes

- Вертикально центрировать микрофон относительно поля ввода, чтобы центры кнопок совпадали.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `opencode-session-attachment`: вертикальное выравнивание элементов строки ввода.

## Impact

Одна строка в `lib/home_components.ml`: использование существующего `center_vertically` у строки ввода OpenCode. Протокол и Android-компоненты уже поддерживают это свойство.
