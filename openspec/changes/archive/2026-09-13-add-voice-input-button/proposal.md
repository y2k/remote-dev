## Why

Нужен голосовой ввод одним удержанием: пользователь нажимает маленькую кнопку-микрофон, говорит и отпускает её, после чего приложение отправляет распознанный текст. Отдельный компонент позволит использовать это поведение в backend-defined UI без привязки к конкретному экрану.

## What Changes

- Добавить отдельный элемент `voice_input` с обязательным `event`, без параметров видимого текста и подписи.
- Отображать компактную кнопку с иконкой микрофона; нажатие запускает распознавание, отпускание останавливает ещё активный захват. Системный сервис может завершить фразу раньше на паузе; окончательный текст отправляется в `value` существующего события только после отпускания.
- Инкапсулировать запись, распознавание, разрешение микрофона и локальные состояния в Android-компоненте; сохранить стандартную доступную область касания.
- Использовать штатный Android `SpeechRecognizer` с языком `ru-RU` и оформление изученного компонента `SpeechInput.kt` из `~/Projects/remote_android_development`.
- Разместить микрофон справа от `Commands` на экране Worktree и `Prompt` на экране OpenCode session. Полученный текст заменяет содержимое поля через backend UI-логику; отправка агенту остаётся по Enter.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `android-backend-driven-ui`: новый самостоятельный элемент голосового ввода и отправка результата через существующий контракт событий.

## Impact

- `lib/components.ml`: конструктор элемента, отображение событий через `map`, JSON-сериализация.
- `lib/home_components.ml`: компоновка обоих полей с микрофоном и обработка `Set_prompt` без запуска агента.
- Android: модель и парсер в `MainActivity.kt`, подключение в `UiNodeContent.kt`, отдельный компонент кнопки, разрешение микрофона в manifest и runtime.
- Существующие OCaml/Android проверки компонентов и событий дополняются сценариями голосового ввода.
- Транспорт `POST /` сохраняется. Отдельный SDK, backend-endpoint или ключи для распознавания не нужны; доступность и использование сети зависят от установленного системного сервиса.
