# Proposal

## Why

Кнопка «Создать новую сессию» сейчас закреплена над прокручиваемыми карточками и постоянно занимает место. Пользователь хочет, чтобы она прокручивалась вместе со списком сессий.

## What Changes

- Разместить кнопку первым элементом общей прокручиваемой области перед карточками сессий.
- Показывать заменяющий кнопку индикатор `Creating session...` в той же области.
- Сохранить доступность создания при пустом списке и ошибке загрузки; после прокрутки вниз возвращаться к кнопке прокруткой к началу.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `opencode-session-attachment`: уточнить требование создания сессии — кнопка над карточками входит в их общую прокручиваемую область.

## Impact

- `lib/home_components.ml`: компоновка чистой функции `Sessions.view`.
- `README.md`: описание расположения кнопки.
- Используется существующая поддержка прокрутки weighted column в Android renderer; новые зависимости и изменения API не требуются.
- Существующие проверки в `test/test_folder_tabs.ml` покрывают создание и навигацию; визуальная проверка подтвердит совместную прокрутку.
