## Why

Список worktree содержит неактивную кнопку `New`, поэтому пользователь не может начать создание новой рабочей ветки из Android-клиента. Нужен минимальный UI-поток, который соберёт имя новой ветки, не добавляя пока побочных эффектов Git.

## What Changes

- Сделать кнопку `New` интерактивной и показать форму создания worktree.
- Добавить одно поле для имени новой ветки, отправляемое по текущему протоколу input-событий.
- Обработать отправку имени как заглушку без запуска Git, создания ветки, worktree или изменения списка.
- Сохранить доступную навигацию назад к списку worktree.

## Capabilities

### New Capabilities
- `worktree-creation-ui`: Backend-defined UI-поток ввода имени новой ветки для будущего создания worktree без выполнения Git-операций.

### Modified Capabilities

Нет.

## Impact

- Добавляется отдельный UI-компонент `New_worktree` и его экранное состояние в `lib/home.ml`.
- Используются существующие узлы `button` и `input` и текущий JSON event envelope; Android-клиент и `lib/runtime.ml` не изменяются.
- Дополняются проверки backend UI в `test/test_remote_dev.ml`.
