## Why

В репозитории отсутствует README, а метаданные Dune содержат шаблонное описание. Внешнему разработчику неясны назначение `remote_dev`, порядок локального запуска, Android-настройка и границы безопасного использования.

## What Changes

- Добавить корневой `README.md` на английском языке с описанием `remote_dev` как локального инструмента для работы с Git worktree и Claude CLI через Android-клиент.
- Описать необходимые зависимости, быстрый запуск backend, сборку Android-клиента и обязательную настройку адреса development backend.
- Задокументировать HTTP event protocol, доступные backend-defined UI nodes и команды проверки.
- Явно ограничить область применения доверенной локальной сетью: сервер не имеет аутентификации и способен запускать Claude CLI с локальными полномочиями пользователя.
