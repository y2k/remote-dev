# Proposal

## Why

Сейчас нажатие на папку только записывает её путь в лог, поэтому пользователь не может перейти из списка проектов к работе с OpenCode. Нужен последовательный переход от папки к её сессиям и переписке внутри выбранной вкладки.

## What Changes

- Нажатие на папку в OpenCode открывает список сессий этой папки в текущей вкладке.
- Список показывает только точное совпадение директории, без подпапок и других worktree; сохраняется существующий предел в 20 недавно обновлённых сессий, применённый внутри папки.
- Над списком отображаются путь и кнопка «Создать новую сессию». Создание сразу открывает пустой чат без промежуточной формы и без отправки промпта.
- Выбор существующей сессии открывает переписку. «Назад» возвращает из чата к сессиям, затем к папкам.
- Каждая вкладка сохраняет собственный экран и состояние навигации; эмулятор остаётся общим.
- Refresh обновляет содержимое активного экрана. Ошибки загрузки и создания отображаются в соответствующей вкладке.
- Существующие промпты, slash-команды, Stop и состояние ожидания ввода продолжают работать в чатах вкладок.

## Примерный вид UI

Схемы иллюстрируют расположение элементов. Подписи сокращены для ASCII-макета: `New session` обозначает кнопку «Создать новую сессию», `Voice` — существующий голосовой ввод, `*` — активную вкладку. Левая область и общая панель эмулятора сохраняют соотношение ширины примерно 2:1.

### 1. Список папок

```text
+------------------------------------------+--------------------+
| Agent: OpenCode                          | Emulators          |
| [* Tab 1][x] [Tab 2][x]             [+]  | [Refresh]          |
+------------------------------------------+--------------------+
| Directories                              |                    |
| /projects                                |                    |
|                                          |   Device preview   |
| [remote-dev                         >]   |                    |
| [my-app                             >]   |                    |
| [website                            >]   |                    |
|                                          |                    |
+------------------------------------------+--------------------+
```

### 2. Сессии выбранной папки

Нажатие на `remote-dev` заменяет содержимое текущей вкладки списком сессий. Путь и кнопка создания расположены над прокручиваемыми строками.

```text
+------------------------------------------+--------------------+
| Agent: OpenCode                          | Emulators          |
| [* Tab 1][x] [Tab 2][x]             [+]  | [Refresh]          |
+------------------------------------------+--------------------+
| /projects/remote-dev                     |                    |
|                                          |                    |
| [+ New session]                          |   Device preview   |
|                                          |                    |
| +--------------------------------------+ |                    |
| | Fix navigation                  idle | |                    |
| | /projects/remote-dev                 | |                    |
| +--------------------------------------+ |                    |
| +--------------------------------------+ |                    |
| | Add session list                busy | |                    |
| | /projects/remote-dev                 | |                    |
| +--------------------------------------+ |                    |
+------------------------------------------+--------------------+
```

Если сессий нет, под кнопкой создания отображается сообщение о пустом списке. Ошибка первоначальной загрузки отображается как ошибка, а не как пустой результат.

### 3. Пустой чат после создания сессии

```text
+------------------------------------------+--------------------+
| Agent: OpenCode                          | Emulators          |
| [* Tab 1][x] [Tab 2][x]              [+]  | [Refresh]          |
+------------------------------------------+--------------------+
| OpenCode session                         |                    |
| <title from OpenCode>                    |                    |
| /projects/remote-dev                     |   Device preview   |
| Status: idle                             |                    |
|                                          |                    |
|                                          |                    |
|                                          |                    |
| [Prompt...                     ] [Voice] |                    |
+------------------------------------------+--------------------+
```

Существующая сессия открывается в той же компоновке, но с перепиской. Системная кнопка «Назад» возвращает из чата к сессиям, затем к папкам. Вкладки и правая панель остаются на месте; переключение вкладок восстанавливает их собственные экраны.

## Capabilities

### New Capabilities

Нет: поведение расширяет существующие возможности.

### Modified Capabilities

- `project-tabs`: собственный экран каждой вкладки, сохранение навигации, адресация событий и Refresh/Back.
- `startup-directory-list`: переход по папке в режиме OpenCode вместо поведения только с логированием; независимость списка папок от OpenCode сохраняется.
- `opencode-session-attachment`: список сессий выбранной папки, создание пустой сессии, навигация и ошибки внутри вкладки.

## Impact

Основные изменения затронут `lib/home_components.ml`, `lib/home.ml`, `lib/runtime.ml` и `lib/server.ml`; проверки — `test/test_runtime.ml` и `test/test_remote_dev.ml`; описание поведения — `README.md`. Используются существующие UI-узлы и opaque events, новые зависимости и клиентская модель навигации не нужны.

Действующие спецификации явно запрещают переход из списка папок и создание сессии; соответствующие требования заменяются delta-спецификациями. Миграция OpenCode V2 выполнена отдельно в `401b293` (`migrate-opencode-v2-api`). Это изменение переиспользует shared-service discovery, authentication из регистрации и готовые runtime-операции списка папки и создания. Отсутствующие название, агент и модель допустимы: название отображается как «Без названия», клиентские defaults не подставляются.
