# Proposal

## Why

Backend обращается к V1 API на фиксированном порту 4096, тогда как установленный OpenCode 2.0.24 использует общий сервис с обнаруживаемым адресом и другим HTTP-контрактом. Миграция восстановит работу существующих экранов сессий и предоставит проверенные runtime-операции для зависимого изменения `folder-sessions-in-tabs`.

## What Changes

- **BREAKING**: заменить V1 API на V2; обнаруживать уже работающий общий сервис по регистрации и проверять `/api/info`, без запуска или остановки сервиса.
- **BREAKING**: получать Basic credentials из регистрации сервиса вместо `OPENCODE_SERVER_PASSWORD` процесса backend; отказаться от фиксированного порта 4096.
- Перевести список, переписку, статусы, pending input, промпты, команды и Stop на проверенный V2-контракт. Сохранить ручное обновление и быстрый ответ Android на отправку.
- Добавить runtime-операции точного списка папки и создания пустой сессии для зависимого UI-change, без подключения новых экранов или кнопок.
- Поддержать необязательное название новой сессии, пагинацию полной переписки и различение ошибок V2 по типу, а не только HTTP-коду.
- Обновить контрактные проверки и инструкции подключения; передать зависимому изменению уточнения о credentials и необязательных defaults.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `opencode-session-attachment`: discovery/authentication общего сервиса V2, чтение переписки и состояния, семантика Stop, runtime-операции списка папки и создания пустой сессии.
- `opencode-cli-execution`: V2-контракт принятия промптов и выполнения slash-команд, типизированные ошибки операций.

## Impact

- `lib/runtime.ml`: транспорт, discovery, JSON-декодеры и операции V2; существующий `Runtime.with_http` остаётся точкой подстановки HTTP в тестах.
- `lib/server.ml`: сохранить быстрый ответ промпта и фоновые slash-команды с новыми статусами HTTP.
- `lib/home_components.ml`: минимальная адаптация к нормализованным данным, если потребуется; TEA и навигация сохраняются.
- `test/test_runtime.ml`, `test/test_remote_dev.ml`, `README.md`: новые fixtures, регрессионные проверки и эксплуатационный контракт.
- Новые зависимости, поддержка V1, управление жизненным циклом OpenCode и реализация вкладок не входят в изменение.
- `folder-sessions-in-tabs` зависит от результата миграции. Его текущие ссылки на старую authentication policy и обязательные defaults требуют согласования перед apply того изменения; его артефакты здесь не редактируются.
