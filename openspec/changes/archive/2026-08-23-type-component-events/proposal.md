## Why

Сейчас UI-компоненты получают уже сериализованный `Yojson.Basic.t`, поэтому действия кнопок и input описываются строковыми тегами в view. Те же теги вручную разбираются при обработке HTTP-запроса, что не позволяет компилятору проверить связь UI-действия с обработчиком страницы.

## What Changes

- Представить дерево UI в `Components` параметризованным типом событий вместо немедленного JSON.
- Передавать page-local типизированные действия непосредственно в `button` и `edit`.
- Поднимать события активной страницы в `Home` и сериализовать их в существующий JSON protocol только при формировании HTTP-ответа.
- Сохранить JSON envelope, имена event tags, Android-клиент и наблюдаемое поведение событий без изменений.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Изменение является внутренним рефакторингом и не меняет специфицированное поведение UI или HTTP protocol.

## Impact

- Затронуты `lib/components.ml`, `lib/home.ml` и OCaml-тесты.
- Новые зависимости, изменения Android-клиента и изменения HTTP API не требуются.
