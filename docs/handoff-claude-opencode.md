# Handoff: исследование работы Claude Code / OpenCode

## Цель следующей сессии

Продолжить практическое исследование управления сессиями Claude Code и OpenCode: получение списка, создание, отправка сообщений в существующие сессии, сохранение контекста. Пользователь общается на русском. Последний фокус пользователя: «иследование работы claude/opencode». Конкретная задача реализации или интеграции пока не задана.

## Что уже проверено

Локально установлен Claude Code `2.1.273`, executable `/opt/homebrew/bin/claude`. Проверки выполнялись из корня проекта `remote_dev`.

### Получение списка

Успешно выполнены:

```sh
claude agents --json
claude agents --json --all
```

Обе команды вернули одну существующую работающую фоновую сессию другого проекта. Её не изменяли. Идентификаторы и имя здесь опущены как ненужные для продолжения.

Согласно локальному `claude agents --help`:
- `--json`: активные интерактивные и фоновые сессии в JSON, без TTY.
- `--all` совместно с `--json`: также завершённые фоновые сессии.
- `--cwd <path>`: фильтр фоновых сессий по каталогу запуска.

Это не полный архив диалогов. До теста создания в каталоге `~/.claude/projects/<encoded-project-path>/` для `remote_dev` были обнаружены три файла сессий `*.jsonl`, которые команды выше не показали. Содержимое этих файлов не исследовали.

### Создание и продолжение: реальный успешный тест

Создание:

```sh
claude -p "Запомни контрольное слово: кедр-7319. Ответь только OK." --output-format json --tools "" --strict-mcp-config --safe-mode
```

Результат: `subtype: success`, `is_error: false`, `result: OK`.

Созданная тестовая сессия:

```text
4a2e3b5d-a070-41b9-b5c7-efb7b0d84e29
```

Продолжение отдельным процессом, без повторной передачи контрольного слова:

```sh
claude --resume 4a2e3b5d-a070-41b9-b5c7-efb7b0d84e29 -p "Какое контрольное слово я просил запомнить? Ответь только им." --output-format json --tools "" --strict-mcp-config --safe-mode
```

Результат: `subtype: success`, `is_error: false`, `result: кедр-7319`; тот же `session_id`. Значит, создание и последовательное продолжение с контекстом проверены. Сессия оставлена для дальнейших экспериментов. Инструменты модели были отключены; использовался safe mode. Поле `total_cost_usd` составило примерно $0.03227 и $0.00294 соответственно.

## Известно из help, но не протестировано

```sh
claude --bg "Описание задачи"  # Создание фоновой сессии
claude attach <id>             # Интерактивное подключение
claude logs <id>               # Недавний терминальный вывод
claude --resume                # Интерактивный выбор сохранённого диалога
```

Не проверяли отправку сообщений в уже занятую сессию, конкурентные обращения, создание фоновой сессии, историю сообщений программным способом и облачные сессии. `claude agents --json --all` не следует представлять как полный список всех сохранённых сессий.

OpenCode CLI/API пока вообще не исследовали. Не переносить выводы о Claude Code на OpenCode без проверки.

## Рекомендуемый следующий шаг

Уточнить конкретный аспект при необходимости, но начать с read-only проверки `opencode --version` и `opencode --help`, затем справки доступных подкоманд управления сессиями/API. Для сопоставления с Claude Code достаточно повторить минимальный тест: создать отдельную тестовую сессию, получить ID, продолжить её и проверить память контрольного слова. Перед использованием команд сверить их с установленной версией. Не трогать посторонние работающие сессии.

## Артефакты и ограничения

- В ходе исследования не создавались планы, specs, ADR, issues, commits или изменения кода проекта. Результаты были только в сообщениях и выводе команд; этот документ фиксирует их.
- Правила репозитория: `AGENTS.md` в корне `remote_dev`; перечитать при продолжении. Не дублируются здесь.
- Активен ponytail full: минимальные решения, сначала понимание реального поведения, без спекулятивных абстракций.
- Не запускать субагентов без явного разрешения пользователя или применимых инструкций.
- Текущий режим build; предыдущая реплика ассистента про read-only больше не актуальна.
- Пользовательские абсолютные пути и детали посторонней сессии намеренно опущены. Секреты в документ не включены. UUID тестовой сессии сохранён как необходимый технический идентификатор, не как credential.
